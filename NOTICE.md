## Firmware

Este projeto não distribui firmware.

O arquivo `.pac` usado no reflash é obtido pelo usuário a partir do instalador oficial do fabricante. Nenhum binário de terceiro é hospedado ou redistribuído neste repositório. Os scripts apenas baixam o instalador do servidor oficial e conferem o SHA-256.

## Escopo

O material descreve procedimentos de recuperação em aparelho de propriedade do usuário, com o objetivo de restaurar o funcionamento e remover software que o próprio usuário não utiliza.

Não há incentivo a burlar mecanismos de segurança de terceiros, nem a acessar dados de outra pessoa.
